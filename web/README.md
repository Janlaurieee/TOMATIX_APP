# Tomatix Web Dashboard

This is the Vercel-ready browser dashboard for Tomatix. It is separate from the Android app and reads Firebase Realtime Database through REST requests.

## Deploy on Vercel

Use either option:

1. Import the repository in Vercel and keep the repo root selected. The root `vercel.json` rewrites traffic to this `web` folder.
2. Or set Vercel's Root Directory to `web` and deploy it as a static site.

No build command is required.
